# RF Signal Processing for Radar Systems

This repository contains a complete RF and radar signal processing project focused on interferometric Angle of Arrival (AOA) estimation, spectral analysis, antenna array geometries and phased array beamforming techniques.

The project combines real radar measurements and synthetic simulations to study:
- Radar I/Q signal behavior
- Cross spectral interferometry
- Direction finding techniques
- Antenna array configurations
- Radiation pattern simulations
- Beam steering and tapering effects

The implementation demonstrates practical applications of RF engineering concepts used in:
- Phased-array radars
- Surveillance systems
- Wireless sensing
- Remote sensing
- Electronic warfare
- Modern communication systems
